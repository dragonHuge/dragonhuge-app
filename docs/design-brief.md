# App 设计简报 v0.1（2026-11-21）

## 目标

把个人站做成手机上的「个人资料库」：看得进、找得到、随时收藏。

## 设计原则

1. 内容优先：卡片与正文占主角，导航退到背景
2. 单手可用：底部 Tab + 顶部搜索
3. 与站点同源：沿用绿主色（#0e7a52）、衬线标题、纸感底色
4. 深色可选：夜间阅读模式

## 信息架构（5 个页面）

1. 首页：问候 + 模块卡（知识 / 问答 / 羊毛 / 需求）+ 最近更新
2. 知识库：分类列表 → 卡片详情（正文 + 原文链接）
3. 搜索：全站搜索，输入即出结果
4. 羊毛线报：按天分组的优惠情报
5. 我的：收藏 / 阅读历史 / 离线缓存 / 关于

底部 Tab：首页 · 知识 · 搜索 · 我的

## 三个设计方向（待选）

### A. 纸感档案（推荐）
- 米白纸底 + 墨绿点缀 + 衬线标题，像一本可翻阅的档案
- 卡片有细边框、轻阴影；列表行距大，适合长读
- 风险：容易做成"文艺博客"，需要在信息密度上克制

### B. 终端索引
- 深色底 + 等宽字体 + 高密度列表，像开发者索引
- 搜索与快捷键优先，适合"我知道我要找什么"
- 风险：阅读长文累，不适合随手翻

### C. 画廊笔记
- 大留白 + 大图 + 极简 chrome，像杂志
- 每屏只讲一件事，滑动节奏强
- 风险：信息密度低，找东西慢

## 组件清单

- 顶部：标题 + 搜索入口（滚动时收起）
- 卡片：标题 / 摘要 / 来源 / 日期
- 详情：正文排版、代码块、图片、原文链接
- 空状态 / 加载骨架 / 离线提示

## 下一步

选定方向后出 3 屏高保真稿（首页 / 列表 / 详情），再进 Capacitor 实现。
